[Fy2Press](https://fy2press.com/) is the WordPress catalog plugin published by [PAGUP](https://pagup.com/). Its software identifier is `https://fy2press.com/product/#software`; the publisher identifier is `https://pagup.com/#organization`.

This reference is a document about that software, distinct from its source distribution. The [document entity](artefacts/repository-entity.jsonld) uses `CreativeWork` and `about`, not software `sameAs`.

Gautier Dorval coordinates the documentation. This does not change the software attribution to PAGUP. Shopify and WordPress are separate platforms; no sponsorship or endorsement is implied.
