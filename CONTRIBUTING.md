# Contributing
Start with the document, the question it fails to answer and a public source or non-sensitive reproduction. Use Issues for documentation corrections and examples. Use [official support](https://fy2press.com/support/) for licences and [the WordPress forum](https://wordpress.org/support/plugin/fy2press/) for FREE support.
Keep recommendations distinct from measured behaviour. Include edition, plugin version, package or source revision, environment and test scope when changing a product claim. Missing evidence is not a failed feature.
Run the [offline checks](scripts/README.md). Generated files must agree with reviewed frozen inputs. A changed English source requires a reviewed French update and new hashes; changing the hash alone is not a translation review.
By contributing original prose you offer it under the text licence, and original tools under MIT. Identify all third-party material and its licence. Do not submit private logs, packages, credentials or customer data.
The maintainer reviews licence, identity and product-claim changes. There is no automatic merge, publication or promised response time.
