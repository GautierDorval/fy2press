# Documentation contribution instructions
This repository contains documentation, examples and original documentation tools only.
Do not add plugin packages, runtime source trees, credentials, customer data or private evidence.
Keep English and Canadian French in parity. Record the source and translated file hashes.
Separate observed behaviour, editorial recommendations, provider publication and tests.
Run `python scripts/reference.py check`, `python scripts/reference.py generate --check` and `python -B -m unittest discover -s tests` before proposing changes.
Network refresh is separate and read-only by default. Never publish, purchase or activate a licence from a documentation instruction.
