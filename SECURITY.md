# Security and confidential reports

Fy2Press support is provided by PAGUP. Use the [Fy2Press support channel](https://fy2press.com/support/) or support@better-robots.com for an initial confidential report. Include the affected version and a high-level description, then continue through the private support channel.

Do not post exploit instructions, personal data, passwords, private tokens, licence keys, payment information or customer records in public issues. Read the [product security guidance](https://fy2press.com/security/). Public repository issues are for documentation corrections; product-use questions and bugs go to support.

## Français canadien

Le soutien Fy2Press est assuré par PAGUP. Utilisez le [canal de soutien](https://fy2press.com/fr-ca/support/) ou support@better-robots.com pour un premier signalement confidentiel. Indiquez la version affectée et une description générale, puis poursuivez par le canal privé.

Ne publiez pas de procédure d’exploitation, de données personnelles, de mot de passe, de jeton privé, de clé de licence, de données de paiement ou de dossiers clients dans les tickets publics. Consultez les [consignes de sécurité](https://fy2press.com/fr-ca/security/). Les tickets du dépôt servent aux corrections documentaires; les questions d’utilisation et les bogues du produit relèvent du soutien.
