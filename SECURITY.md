# Security and confidential reports
Do not open a public issue containing an exploitable vulnerability, credentials, licence keys, payment information or customer records.
Use the [Fy2Press support channel](https://fy2press.com/support/) for a confidential initial report. Start with the affected version and a high-level description; do not attach secrets. The published support route is available, but delivery of a confidential report has not been tested by this documentation work. No response deadline is promised.
Read the [product security guidance](https://fy2press.com/security/). For public documentation corrections, use the documentation issue form.
